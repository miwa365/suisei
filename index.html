ライブのおおまかな流れです。はじめて配信に入るときの参考にどうぞ。

  1. PHASE 01 // CENTER DANCE

    センターダンス

    全員で踊るオープニング。好きなアイテムをプレゼントして応援しましょう。コンボ優先が合言葉です。

    コンボとは？　同じギフトを続けて送ること。連続で送ると画面に「×2」「×3」…と数字が重なって表示され、盛り上がりがひと目で伝わります。高額ギフトを1回送るより、小さなギフトをみんなで連打する方がライブが熱くなります。
  2. PHASE 02 // TRIO BATTLE

    3人ダンス（勝ち残り戦）

    3人で踊り、2分間で集まったポイントの上位2名が勝ち残り。1000ポイントに届くと、ほかの2人にたのしい罰ゲームが待っています。

    推しを勝ち残らせたいときは、2分間の勝負どころでコンボを。ギフトが難しいときは、コメントで声援を送りましょう。
  3. PHASE 03 // PK BATTLE

    PK（対戦）タイム

    ほかの配信ルームとつながり、制限時間内に集まったギフトのポイントで勝敗を競います。負けた側には罰ゲームがあることも。

    勝ち負けより「楽しむ」が大事。コメントやタップで場をあたためるのも立派な応援です。
  4. PHASE 04 // SOLO & REQUEST

    ソロ・指名タイム

    メンバーが一人ずつ前に出て踊ったり、リクエストに応えたりする時間。推しが一番近くに来てくれるチャンスです。

    担当メンバーの応援アイテムを送ると、誰を応援しているかが伝わりやすくなります。
  5. PHASE 05 // TALK

    トーク・交流タイム

    ダンスの合間に、コメントを読んだり話しかけてくれたりする時間です。

    日本語の挨拶や、下の「TRANSMISSION TERMINAL」の中国語フレーズを送ってみましょう。
  6. PHASE 06 // ENDING

    エンディング

    締めのダンスと挨拶。最後まで見てくれたファンへの感謝が伝えられます。

    「辛苦了（おつかれさま）」の一言は、何よりの応援になります。
